# Fahrtenbuch-App (iPhone)

## So benutzt du sie
1. **Fahrt starten** tippen, wenn du losfährst. Startzeit und Standort werden gespeichert.
2. Während der Fahrt die App offen lassen (Bildschirm bleibt an), dann wird die Strecke per GPS mitgeschrieben.
3. **Fahrt beenden** tippen. Ziel-Adresse und Kilometer werden automatisch eingetragen, du ergänzt nur den Zweck.
4. Vergessen? **Fahrt nachtragen**, Adressen eingeben, "Strecke aus Adressen berechnen".
5. Zum Jahresende: **Export & PDF** für die Excel-Tabelle oder das PDF fürs Finanzamt.

## Wichtig
- Die Daten liegen nur auf deinem iPhone. Unter **Sicherung** regelmäßig eine Sicherung in iCloud Drive speichern.
- Wird die App während der Fahrt geschlossen, berechnet sie die km am Ende über die Route (Start → Ziel). Umwege fehlen dann.
- Nachträgliche Änderungen werden je Fahrt protokolliert und im Export markiert.
- Kilometergeld: 0,50 €/km (PKW, seit 2025), höchstens 30.000 km pro Jahr. In den Einstellungen änderbar.
- Fahrten Wohnung ↔ Arbeitsplatz gehören nicht ins Fahrtenbuch (Pendlerpauschale).

## Aufs iPhone bringen
Die App braucht eine https-Adresse (wegen GPS). Den Ordner z.B. über GitHub Pages veröffentlichen,
dann in Safari öffnen → Teilen → "Zum Home-Bildschirm". Beim ersten Start den Standortzugriff erlauben.

Adressen: OpenStreetMap (Nominatim), Route: OSRM, Link zu Google Maps pro Fahrt.
